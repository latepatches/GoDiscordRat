## Commands

| Command | Description |
|---|---|
| `.help` | Displays available commands. |
| `.exec (cmd)` | Executes a system command. |
| `.run (file link)` | Runs a file from a provided link. |
| `.screenshot` | Captures a screenshot. |
| `.ip` | Retrieves the public IP address. |
